# Local Dev Server

## Goal
Serve the atlas locally for UI/data iteration without any install step.

## Prerequisites
- Python 3 (or any static file server)
- Repository root as document root

## Steps
1. `python3 -m http.server 8000`
2. Open `http://localhost:8000` (English UI: `http://localhost:8000/?lang=en`; Traditional: `?lang=zh-tw`)
3. After editing `css/` or `js/`, run `node scripts/sync_version.js` and hard-reload (cache-busting hashes change)
4. For a containerized check: `docker compose up -d --build`, then open `http://localhost:8008`

## Expected Outcome
Atlas loads with timeline, map, and search; edited bundles appear after hash sync + reload.

## Common Pitfalls
- Editing `js/atlas_snapshots.js` or `js/atlas_boot.js` by hand: they are generated by `scripts/build_atlas.js`
- Forgetting `sync_version.js`: `index.html` keeps the old hash and the browser serves a stale bundle
- Serving from a subdirectory: deep links assume the repo root is the document root
