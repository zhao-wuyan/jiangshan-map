# Electron 桌面壳与 Windows 全屏陷阱

## 场景
把零依赖静态网页（本项目 index.html + js/*.js IIFE bundle）包装成离线 Electron 桌面应用（Windows 10+，目标希沃教学一体机），不引入打包器、不改变网页运行方式。

## 关键决策与原因
- **自定义协议而非 file:// 或本地 HTTP**：`protocol.registerSchemesAsPrivileged([{scheme:'atlas',privileges:{standard:true,secure:true,supportFetchAPI:true,stream:true}}])` 在 app ready 前调用；`protocol.handle('atlas', ...)` 流式提供 `desktop/web`。fetch/XHR/audio 正常、无监听端口、无 CORS 问题。file:// 下 fetch 会失败，本地 HTTP 会被校园网代理/防火墙干扰。
- **同源校验不能比较 origin 字符串**：自定义 scheme 的 `new URL('atlas://app/').origin` 在部分版本序列化为 `"null"`。IPC sender 校验必须解析 URL 后比较 `protocol === 'atlas:' && hostname === 'app' && !port && !credentials`。
- **全屏切换的 Windows 陷阱**：`setFullScreen(target)` 可能在调用内**同步**触发 `enter-full-screen` 事件。若在 Promise executor 里同步清理 guard（`fullscreenChange = null`），guarded promise 永远不会被赋值（第二次切换直接丢失或死锁）。修法：executor 只挂监听，`fullscreenChange = transition.finally(() => { fullscreenChange = null; })` 在赋值后异步清理。回归测试用真实 Electron 子进程连续 3 次进/出全屏（desktop/test-fullscreen.cjs），mock 事件测不出这个问题。
- **视觉一致性：桌面样式不得重排既有控件**。给 `.action-btn` 全局加 44px 触控最小尺寸会撑坏地图图例的 `.phase-dot` 等紧凑控件；替换字体栈也会改变度量。正解：桌面 CSS 只允许对新增元素（设置面板）作用域内覆盖；网页字体用 @font-face 指向本地打包的同名 TTF，保持 `font-family` 解析结果与线上一致。用同视口对比 desktop vs 网页 computed metrics（按钮/印章/搜索框宽高、document.fonts.check）验证。
- **字体来源**：google/fonts 仓库 `ofl/<family>/` 的可变 TTF + OFL.txt。下载脚本按 git blob SHA-1（`blob <len>\0` 前缀）校验后存 `desktop/fonts/`（gitignore），prepare 阶段复制进包。可变 TTF 用 `font-weight: 200 900` 区间声明。
- **electronDist 复用本地 Electron**：electron-builder 配 `"electronDist": "node_modules/electron/dist"`，避免重复下载运行时 zip（离线/弱网构建环境关键）。
- **偏好持久化**：写 `userData/atlas-preferences.json`（临时文件+rename 原子写）；尊重 `--user-data-dir`（在 ready 前 `app.setPath('userData', ...)`），测试可隔离。显卡兼容模式必须在 ready 前 `disableHardwareAcceleration()`，改动走原生确认+relaunch。

## 已验证
- Windows 11 x64 + Electron 45.2.3：断网（webRequest 拦截 http/https/ws/wss）下地图、搜索、人物行迹、本地古琴音频（含 Range 206/后缀 range）、地形瓦片全部可用。
- 相同视口下桌面与网页的控件尺寸/字体度量一致；流畅模式默认关闭、开启后地图内容保留仅降运动开销。

## 陷阱清单
- `--user-data-dir` 是 Chromium 标准 switch，Electron 需手动 `app.commandLine.getSwitchValue` + `setPath` 才真正隔离。
- 打包 asar 内 `fs.promises.realpath` 依赖 Electron 补丁 fs 返回虚拟路径（可用，但语义与裸 Node 不同）。
- 沙箱 preload 里没有 `process.isMainFrame`；主框架判定靠 `nodeIntegrationInSubFrames: false` + `event.senderFrame === event.sender.mainFrame`。
